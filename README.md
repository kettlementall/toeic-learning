# TOEIC Learning Platform

An AI-assisted TOEIC vocabulary and grammar trainer. Register an account, look
up real words from an online dictionary, build your **own** vocabulary library,
review it with a spaced-repetition (SM-2) scheduler, and take AI-generated
quizzes (vocabulary multiple-choice, Part 5 grammar, sentence fill-in-the-blank)
that adapt to your weak points. A dashboard tracks your progress, error rates by
grammar point and part of speech, and "leech" words you keep getting wrong.
Every user's library, quizzes, and stats are private to them; an administrator
can manage accounts.

> **Security note:** keep your `ANTHROPIC_API_KEY` in `backend/.env`, which is
> git-ignored and never committed. If a key is ever exposed, rotate it in the
> Anthropic Console. See [Configuration](#configuration).

## Features

- **Accounts** — open self-service registration; each user gets a private
  training database (vocabulary, quizzes, review history, dashboard). Sign in
  with a unique **account id** (your chosen `name`) — email is optional. Session
  cookie auth. Administrators (`is_admin`) get a user-management screen to list
  users with per-user stats and create / disable / delete accounts and reset
  passwords. Disabled accounts (`is_active=false`) cannot log in.
- **Word search** — look up any English word via the free
  [dictionaryapi.dev](https://dictionaryapi.dev) API; Claude enriches it with
  Traditional Chinese translations (per part of speech) and a TOEIC usage note.
  Looked-up words are auto-added to your library.
- **Vocabulary library** — every word you search, quiz, or get flagged on is
  stored with notes, tags, and SM-2 scheduling state. Filter by source/tag,
  edit notes, delete entries.
- **Daily review** — SM-2 spaced repetition surfaces words that are due. You
  self-grade recall 0–5; the interval, ease factor, and next review date update
  accordingly. Words failed repeatedly become "leeches".
- **AI quizzes** — three types, all generated by Claude:
  - **Vocabulary MC** — 4-option meaning/usage questions.
  - **Part 5 Grammar** — TOEIC-style sentence-completion across 10 grammar
    points, selected adaptively by your past error rate.
  - **Fill-in-the-Blank** — word-form completion questions.
  Quiz selection can be a *smart mix* (≈70% weak/due + 30% new words), *weak
  points only*, or *custom* (by category/level/tag). Correct/incorrect answers
  feed straight back into the SM-2 scheduler and grammar stats.
- **AI quiz review** — after submitting, Claude writes a summary, a weakness
  analysis, and suggests words/grammar points to drill. Suggestions are fed back
  into the review queue and the adaptive grammar engine.
- **Dashboard** — totals, due count, completed quizzes, average accuracy, a
  recent-score trend, grammar-weakness ranking, vocab weakness by part of
  speech, leech list, and the latest AI-recommended grammar focus.
- **Responsive UI** — the top navigation collapses into a hamburger menu on
  phones (<768px).
- **Built-in TTS** — the browser's speech synthesis pronounces any word, even
  ones with no recorded dictionary audio.

## Getting Started

### Option A — Docker (recommended)

Requirements: Docker + Docker Compose.

```bash
# from the repo root
cp backend/.env.example backend/.env      # then edit DB + ANTHROPIC_API_KEY (see below)
docker compose up -d --build

# one-time app setup inside the php container
docker compose exec php composer install
docker compose exec php php artisan key:generate
docker compose exec php php artisan migrate --seed
docker compose exec php npm install
docker compose exec php npm run build
```

The app is served at **http://localhost:8080**. MySQL is exposed on host port
**3307** (container 3306).

The migration seeds a default **admin** account — login id **`wells`**, password
`password` — which also owns any data that predates the accounts system.
**Change this password after first login** (Admin → your row → Reset password).
Everyone else signs up at `/register`.

> **Login uses an account id**, not email. You sign in with the `name` you chose
> at registration (the seeded admin's id is `wells`). Email is optional and only
> kept for reference.

The Docker `.env` should point the DB at the compose service:

```dotenv
DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=toeic_learning
DB_USERNAME=toeic
DB_PASSWORD=secret
APP_URL=http://localhost:8080
```

### Option B — Local (no Docker)

Requirements: PHP 8.3+, Composer, Node 18+. SQLite is the simplest DB.

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate

# use SQLite
# in .env set: DB_CONNECTION=sqlite  (remove the DB_HOST/PORT/etc. lines)
touch database/database.sqlite

php artisan migrate --seed
npm install
npm run build

# run everything (server + queue + logs + vite) with one command:
composer run dev
# ...or just the web server:
php artisan serve   # http://127.0.0.1:8000
```

## Configuration

Set these in `backend/.env`:

| Variable             | Purpose                                            | Default                                              |
|----------------------|----------------------------------------------------|------------------------------------------------------|
| `ANTHROPIC_API_KEY`  | Anthropic Claude API key. **Required** for word enrichment, quiz generation, and AI review. | *(none)* |
| `ANTHROPIC_MODEL`    | Claude model ID.                                   | `claude-sonnet-4-6`                                  |
| `DICTIONARY_API_URL` | Base URL for the dictionary lookups.               | `https://api.dictionaryapi.dev/api/v2/entries/en`    |
| `DB_*`               | Database connection.                               | MySQL (Docker) / SQLite (local)                      |

The app **degrades gracefully without an API key**: dictionary lookups (English
definitions, phonetics, audio) still work; only the AI features (Chinese
translation, quiz generation, AI review) are disabled, with a banner shown on
the relevant pages. `ClaudeService::hasKey()` gates all AI calls.

> **Keep the key in `.env` only.** `backend/.env` is git-ignored (Laravel's
> default `.gitignore`, plus a root-level `.gitignore`, both exclude it), so the
> key stays out of version control. Rotate it in the Anthropic Console if it is
> ever exposed.

## Usage

1. **Look up words** (`/words`) — search any English word. It's added to your
   library automatically and you can hear it pronounced.
2. **Review** (`/review`) — work through due words; grade your recall 0–5.
3. **Quiz** (`/quiz/create`) — pick a type and strategy, generate, take it,
   then read the AI review.
4. **My Vocabulary** (`/vocabulary`) — browse/filter your library, add notes and
   tags, remove words.
5. **Dashboard** (`/`) — track progress and see where you're weakest.

|--------|---------------------------|---------------------|--------------------------------------|
| GET    | `/register`               | `register`          | Registration form (guest)            |

| POST   | `/login`                  | —                   | Authenticate                         |
| POST   | `/logout`                 | `logout`            | Log out                              |

| GET    | `/words/example?q=`       | `words.example`     | Get/generate one example (JSON)      |

| POST   | `/quiz`                   | `quiz.store`        | Generate a quiz                      |
| GET    | `/quiz/{quiz}`            | `quiz.show`         | Take the quiz                        |
| POST   | `/quiz/{quiz}/submit`     | `quiz.submit`       | Submit answers                       |
| GET    | `/quiz/{quiz}/review`     | `quiz.review`       | Results + AI review                  |
| GET    | `/admin/users`            | `admin.users.index` | User list + stats (admin)            |
| POST   | `/admin/users`            | `admin.users.store` | Create a user (admin)                |

> **Per-user data.** Every request runs as the logged-in user; vocabulary,
> quizzes, and review history are scoped by `user_id`. The shared `words`
> dictionary/seed cache stays global. Ownership is enforced on each route
> (route-model-bound `UserWord`/`Quiz` return 403 for non-owners).

## Maintenance Commands

```bash
# Backfill missing example sentences for words in the vocabulary library:
#  - links orphaned words to a dictionary entry (which may supply an example)
#  - generates an AI example for any library word still missing one
php artisan words:backfill-examples              # up to 200 words, 20 per AI request
php artisan words:backfill-examples --limit=50   # cap the AI calls
php artisan words:backfill-examples --chunk=10   # fewer words per AI request
```

Cards with no stored example also generate one **on the fly**: the daily-review
card does it automatically when you reveal the answer, and each vocabulary-list
card shows a "✨ Generate example" button. Results are saved, so each word is
only generated once.
